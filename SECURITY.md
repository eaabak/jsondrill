# Security Policy

JSONDrill runs inside Chrome DevTools and can read API responses that contain credentials,
personal data and other sensitive values. Security reports are taken seriously.

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/eaabak/jsondrill/security/advisories/new).

Include:

- a description of the issue and its impact
- steps or a minimal sample response to reproduce it
- the JSONDrill and Chrome versions you used

You can expect an acknowledgement within seven days. Once a fix is released, the advisory is
published with credit to the reporter unless you prefer to remain anonymous.

## Scope

In scope: the extension source in this repository and the packages published from it.
Out of scope: vulnerabilities in Chrome itself or in the sites being inspected.
