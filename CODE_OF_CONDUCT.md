# Code of Conduct

JSONDrill follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone participating in issues, pull requests and discussions is expected to uphold it.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer,
[@eaabak](https://github.com/eaabak), through the private contact options on their GitHub
profile. Reports are reviewed promptly and handled confidentially.

The maintainer may remove, edit or reject contributions, and temporarily or permanently ban
participants, for behaviour that violates this code of conduct.
